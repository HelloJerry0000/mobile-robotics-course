# 04 — ROS 2 基礎

本章介紹 Week 00 需要理解的 ROS 2 最基本概念。

第一週的目標不是一次學完 ROS 2，而是先理解：

- Topic 是什麼

## 1. ROS 2 是什麼？

ROS 2（Robot Operating System 2）是一套用來開發機器人軟體的工具與通訊框架。

在本課程中，可以先把它理解成：

```text
感測器程式
    ↓
ROS 2 通訊
    ↓
定位 / 建圖 / 控制程式
    ↓
機器人
```

實際的機器人系統通常包含許多不同功能。ROS 2 讓我們可以把這些功能拆成不同程式，再透過標準化的方式交換資料。

---

## 2. Node

ROS 2 中，一個正在執行、負責某項功能的程式通常稱為 **Node**。

例如：

```text
Camera Node        讀取相機
LiDAR Node         讀取雷射資料
Controller Node    控制機器人
SLAM Node          建立地圖
```

查看目前正在執行的 Node：

```bash
ros2 node list
```

若想進一步了解某個 Node，可以使用：

```bash
ros2 node info <node_name>
```

---

## 3. Topic

Topic 是 ROS 2 中常見的資料傳輸方式之一。

概念上：

```text
Publisher
    │
    │ 發布資料
    ▼
  Topic
    │
    │ 接收資料
    ▼
Subscriber
```

Publisher 不需要直接知道 Subscriber 是誰；雙方透過共同的 Topic 傳遞資料。

查看目前系統中的 Topic：

```bash
ros2 topic list
```

---

## 4. Message

Topic 傳送的資料需要有明確格式，這個格式稱為 **Message type**。

可以把它想成雙方事先約定好的資料格式：

```text
Publisher
    │
    │ Message
    ▼
  Topic
    │
    │ Message
    ▼
Subscriber
```

查看某個 Topic 的資訊：

```bash
ros2 topic info <topic_name>
```

知道 Message type 後，可以進一步查看其內容：

```bash
ros2 interface show <message_type>
```

---

## 5. Talker / Listener 範例

我們利用 ROS 2 內建範例觀察最基本的 Publisher / Subscriber 通訊。

開啟第一個 Terminal：

```bash
ros2 run demo_nodes_cpp talker
```

再開啟第二個 Terminal：

```bash
ros2 run demo_nodes_py listener
```

Talker 會持續發布訊息，而 Listener 會接收訊息。

概念如下：

```text
Talker Node
 Publisher
     │
     ▼
 /chatter
     │
     ▼
Subscriber
Listener Node
```

---

## 6. 自己觀察 ROS 2 系統

保持 Talker / Listener 執行，再開啟另一個 Terminal。

### 找出正在執行的 Node

```bash
ros2 node list
```

### 找出目前存在的 Topic

```bash
ros2 topic list
```

### 查看 Topic 資訊

```bash
ros2 topic info /chatter
```

觀察輸出中的 Message type、Publisher count 與 Subscription count。

### 查看 Topic 正在傳送的資料

```bash
ros2 topic echo /chatter
```

使用：

```text
Ctrl + C
```

即可停止目前執行中的指令。

### 查看 Message 格式

先利用 `ros2 topic info` 找到 `/chatter` 的 Message type，再自行使用：

```bash
ros2 interface show <message_type>
```

觀察這個 Message 裡包含哪些資料。

## 7. Week 00 的 ROS 2 探索方法

之後遇到一個不熟悉的 ROS 2 系統時，可以先按照下面的順序探索：

```text
ros2 node list
        ↓
ros2 topic list
        ↓
ros2 node info <node_name>
        ↓
ros2 topic info <topic_name>
        ↓
ros2 topic echo <topic_name>
        ↓
ros2 interface show <message_type>
```

這些工具的目的不是背指令，而是讓你能回答：

```text
有哪些程式正在執行？
它們透過哪些 Topic 溝通？
Topic 傳送什麼資料？
資料格式長什麼樣子？
```

這也是 HW00 最重要的能力之一。

## 8. 基本心智模型

Week 00 請先記住：

```text

│    Node A    │
│  Publisher   │
└──────┬───────┘
       │
       │ Message
       ▼
     Topic
       │
       ▼
┌──────────────┐
│    Node B    │
│  Subscriber  │
└──────────────┘
```
