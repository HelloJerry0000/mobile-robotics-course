# 03 — ROS 2 基礎

本章介紹 Week 00 需要理解的 ROS 2 最基本概念。

第一週的目標不是一次學完 ROS 2，而是先理解：

- Node 是什麼
- Topic 是什麼
- Publisher / Subscriber 如何溝通
- 如何用 `ros2` 指令觀察系統
- 如何使用 Turtlesim 進行第一個移動控制練習

---

## 1. ROS 2 是什麼？

ROS 2（Robot Operating System 2）是一套用來開發機器人軟體的工具與通訊框架。

在本課程中，可以先把它理解成：

```text
感測器程式
    ↓
ROS 2 通訊
    ↓
定位 / 建圖 / 控制程式
    ↓
機器人
```

不同功能可以拆成不同程式，再透過 ROS 2 互相交換資料。

---

## 2. Node

ROS 2 中，一個正在執行、負責某項功能的程式通常稱為 **Node**。

例如：

```text
Camera Node        讀取相機
LiDAR Node         讀取雷射資料
Controller Node    控制機器人
SLAM Node          建立地圖
```

查看目前正在執行的 Node：

```bash
ros2 node list
```

---

## 3. Topic

Topic 是 ROS 2 中常見的資料傳輸方式。

概念上：

```text
Publisher
    │
    │ 發布資料
    ▼
  Topic
    │
    │ 接收資料
    ▼
Subscriber
```

例如機器人速度控制常會使用：

```text
/cmd_vel
```

感測器則可能發布：

```text
/scan
/odom
```

這些會在後續 TurtleBot3 課程實際使用。

---

## 4. Talker / Listener 範例

開啟第一個 Terminal：

```bash
ros2 run demo_nodes_cpp talker
```

再開啟第二個 Terminal：

```bash
ros2 run demo_nodes_py listener
```

你應該會看到 Talker 不斷送出訊息，而 Listener 接收到同樣內容。

可以把它理解成：

```text
Talker Node
 Publisher
     │
     ▼
 /chatter
     │
     ▼
Subscriber
Listener Node
```

---

## 5. 觀察 ROS 2 系統

保持 Talker / Listener 執行，再開啟第三個 Terminal。

### 查看 Node

```bash
ros2 node list
```

### 查看 Topic

```bash
ros2 topic list
```

### 查看 Topic 資訊

```bash
ros2 topic info /chatter
```

### 直接查看 Topic 資料

```bash
ros2 topic echo /chatter
```

停止 `echo`：

```text
Ctrl + C
```

---

## 6. ROS 2 的基本心智模型

Week 00 請先記住這張圖：

```text
┌──────────────┐
│  Node A      │
│  Publisher   │
└──────┬───────┘
       │
       │ Topic
       ▼
┌──────────────┐
│  Node B      │
│  Subscriber  │
└──────────────┘
```

之後的 Mobile Robotics 只是把資料換成更實際的內容：

```text
Velocity Command → /cmd_vel
Odometry         → /odom
LiDAR            → /scan
```

# Turtlesim

## 7. 啟動 Turtlesim

Turtlesim 是 ROS 2 經典的入門範例，可以用來理解 Topic 與速度控制。

Terminal 1：

```bash
ros2 run turtlesim turtlesim_node
```

你應該會看到一個有小烏龜的視窗。

---

## 8. 使用鍵盤控制 Turtle

Terminal 2：

```bash
ros2 run turtlesim turtle_teleop_key
```

依照 Terminal 提示使用方向鍵控制 Turtle。

這時候可以再開一個 Terminal：

```bash
ros2 topic list
```

你會看到 Turtlesim 使用的 Topic，例如：

```text
/turtle1/cmd_vel
/turtle1/pose
```

---

## 9. 觀察速度控制 Topic

執行：

```bash
ros2 topic info /turtle1/cmd_vel
```

再執行：

```bash
ros2 topic echo /turtle1/cmd_vel
```

接著在 teleop Terminal 按方向鍵。

你會看到速度指令被發布到 `/turtle1/cmd_vel`。

---

## 10. Twist 訊息

Turtlesim 的速度控制使用：

```text
geometry_msgs/msg/Twist
```

可以查看訊息格式：

```bash
ros2 interface show geometry_msgs/msg/Twist
```

Week 00 最重要的是其中兩個值：

```text
linear.x
angular.z
```

概念上：

```text
linear.x   → 往前 / 往後
angular.z  → 左轉 / 右轉
```

這也是下一週控制 TurtleBot3 時會再次使用的概念。
